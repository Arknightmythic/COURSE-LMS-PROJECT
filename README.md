# 💻 Web Course LMS – Full-Stack JavaScript MERN 2025

Belajar React 18 dan Backend Development dengan Express & MongoDB

## 🚀 Deskripsi

**Web Course LMS** adalah platform pembelajaran daring yang dikembangkan menggunakan teknologi **Full-Stack JavaScript (MERN Stack)**. Proyek ini merupakan bagian dari kelas full-stack developer yang dirancang untuk pemula hingga mahir, mencakup pengembangan frontend dan backend secara menyeluruh.

Dalam proyek ini, saya mempelajari:

- Mengembangkan antarmuka pengguna interaktif menggunakan **React 18** & **Tailwind CSS**.
- Mengelola state data dan fetching API dengan **React Query**.
- Membangun form kompleks dengan validasi menggunakan **React Hook Form** & **Zod**.
- Membuat RESTful API menggunakan **Express.js** dan **MongoDB**.
- Menangani autentikasi dan otorisasi menggunakan **JWT (JSON Web Token)**.
- Mengimplementasikan **file upload** dengan **Multer**.
- Mengintegrasikan **payment gateway Midtrans** untuk pembayaran online.
- Mengelola data dinamis seperti course, student, dan konten dengan fitur **CRUD**.



## 🧠 Teknologi yang Digunakan

### Frontend
- ⚛️ React 18
- 💨 Tailwind CSS
- 🔄 React Query
- ✅ React Hook Form + Zod Validation

### Backend
- 🖥️ Express 4
- 🗃️ MongoDB + MongoDB Compass
- 🧩 Mongoose
- 🔐 JWT Authentication
- 📂 Multer (file upload)
- 💳 Midtrans (payment integration)
